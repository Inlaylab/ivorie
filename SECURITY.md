# Security policy

## Supported versions

| Package | Version | Supported |
|---|---|---|
| `@inlaylab/ivorie` | 1.x | yes |
| `ivorie` (CLI) | 1.x | yes |

Only the latest 1.x release gets security fixes.

## Report a vulnerability

Do not open a public issue.

Report it privately through GitHub:
https://github.com/Inlaylab/ivorie/security/advisories/new

Include:
- the package and version
- steps to reproduce, or a minimal example
- the impact you expect

## What to expect

- We confirm receipt within 5 working days.
- We share a first assessment within 10 working days.
- We fix confirmed issues in a patch release and credit you in the advisory, unless you prefer not to be named.

Please give us time to ship a fix before you disclose the issue.

## Scope

In scope: the `@inlaylab/ivorie` library and the `ivorie` CLI, including the component source the CLI copies into your app.

Out of scope: the docs site content, and issues in your own app, Angular, Tailwind or other dependencies. Report those upstream.
