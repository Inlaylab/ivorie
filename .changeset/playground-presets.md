Presets for the whole look. 7 base colors (neutral, stone, zinc, mauve, olive, mist, taupe), 26 fonts, a heading font and 5 radius options. `ivorie init` applies font, heading font and radius (new flags `--font`, `--font-heading`, `--radius`). New command `ivorie apply <preset|ivp1_…>` changes the look of an existing app. Card, dialog and alert dialog titles use the heading font (`.cn-font-heading`, `--font-heading`). Make a preset in the new docs playground.
