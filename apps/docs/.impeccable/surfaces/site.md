# Surface: Ivorie docs site (home, docs, playground, roadmap)

Mode: Persuade on `/`; Read on docs pages; Operate on `/playground`.

## Direction contract

THESIS: A type foundry's specimen sheet. One sample, set many ways: the same Ivorie component shown in many themes. It refuses the glass, glow and gradient-beam dev-tool hero.

OWN-WORLD: Black ink on white paper (dark mode: paper-white ink on near-black). One action blue. Hairline specimen rules divide rows. Funnel Display at tight tracking for headings, Funnel Sans for text, Geist Mono only for code and commands. Flat surfaces, a small radius, no shadows except on overlays.

STORY: A visitor sees what Ivorie is (Angular 22 components with shadcn/ui behaviour), sees one component in many themes, copies `npx ivorie init`, and finds any component's docs in two clicks.

FIRST VIEWPORT: A large left-set headline and one sentence, with Get started and Playground actions and the install command. On the right, a specimen column: the same live button and switch in five themes, each row labelled with its theme name.

FORM: Type specimen sheet, my own list position 1 (impeccable's pick), chosen by the user over the assigned recipe card file. seed:be709eb84d9e7ebe

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
